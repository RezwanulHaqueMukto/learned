# Learned — Education Website Template

A modern, responsive **HTML, CSS, and JavaScript** template designed for schools, colleges, universities, or online learning platforms. It provides structured layouts to showcase courses, departments, news, and admission details with a professional design.

## ✨ Features

* Responsive layout for desktop, tablet, and mobile
* Hero section with call-to-action (Apply Now)
* Course and department listings
* News and updates section
* About, Admission, and Contact pages
* Clean footer with useful links

## 🚀 Demo

[Live Preview](https://rezwanulhaquemukto.github.io/learned/)

## 📂 Project Structure

```
learned/
│── index.html      # Main HTML file
│── style.css       # Stylesheet
│── script.js       # JavaScript interactivity
│── /assets         # Images, icons, and other assets
```

## ⚡ Usage

1. Clone the repository:

   ```bash
   git clone https://github.com/rezwanulhaquemukto/learned.git
   ```
2. Open `index.html` in your browser.
